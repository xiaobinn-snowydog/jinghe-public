## 一、先记住几个数

热导率（W·m⁻¹·K⁻¹），越大越会导热：

| 材料 | 热导率 | 备注 |
| --- | --- | --- |
| 硅 Si | ~150 | 主流衬底 |
| 碳化硅 SiC | ~400 | 目前 GaN 射频器件的主流衬底 |
| 铜 | ~400 | 金属散热器的基准 |
| CVD 多晶金刚石 | 1000 ~ 2200+ | 看晶粒大小，晶粒越大导热越好 |
| **单晶金刚石** | **2000 ~ 2400** | 固态材料导热极限，铜的 5–6 倍 |
| 金刚石铜复合材料 | 600 ~ 900（量产） | 热膨胀系数可调，成本相对低 |

**金刚石的导热约是 SiC 的 5 倍。** 整条产业逻辑从这个数字开始。

另外两个词要认识：

- **TBR / TBC**（热边界电阻 / 热边界电导）——两块材料交界处多出来的那部分热阻。**界面做不好，金刚石的高导热就白搭。** 这是整个方向的核心指标。
- **CTE**（热膨胀系数）——两种材料热胀冷缩不一样，一加热冷却就翘曲开裂。这是过去几十年"金刚石贴不上"的根本原因。

## 二、为什么现在谈这件事

**驱动力**

- **AI 芯片功耗**：H100/B200 这一代把散热推到了台面上
- **先进封装**：CoWoS、混合键合是确定的产业趋势
- **5G/6G 射频**：GaN 功放的散热直接决定基站的运维成本
- **光通信 / CPO**（光电共封装）：功耗密度大，光器件怕热
- **新能源车**：电控模块的功率器件散热

**但市场阶段要看清。** 据 Yole 的行业分析（2026 年中文转述）：

> GaN-on-AlN 与 GaN-on-Diamond 因高成本、制造复杂、认证周期长，**仍将处于研发阶段**。

同一份分析还提到：GaN-on-SiC 正从 4 英寸向 6 英寸迁移，但比预期慢；通信基础设施（以 GaN-on-SiC 为主）预计以 CAGR 11% 增长至 2031 年。

**这条是本文最重要的一句。** 它决定这个方向的时间感：路是通的，但规模还没到。

## 三、材料端：三条金刚石路线

据 2026-09 行业文章《金刚石铜 vs 纯 CVD 金刚石 vs 单晶金刚石》：

| 路线 | 热导率 | 热膨胀系数 | 尺寸能力 | 成本 | 主要场景 |
| --- | --- | --- | --- | --- | --- |
| **金刚石铜复合材料** | 600–900（量产） | 可调，4–10 ppm/K | 大尺寸容易 | 最低 | IGBT、激光器热沉 |
| **纯 CVD 多晶金刚石** | 1000–2200+ | ~1 ppm/K | 8 英寸热沉片已量产 | 中 | 半导体散热主流路线 |
| **单晶金刚石** | 2000–2400 | ~1 ppm/K | 量产集中 1–2 英寸；2026 年 Element Six 与 Orbray 做到 3 英寸可重复；4 英寸开发中 | 最高 | 国防、卫星、6G 射频等性能优先场景 |

**三条路线各自的工程瓶颈**：

- **金刚石铜**：金刚石与铜几乎不润湿（接触角约 140°），必须在金刚石表面镀钛、铬等碳化物形成元素，才能建立有效传热通道。
- **多晶金刚石**：太硬，切不动磨不动，工具磨损快、加工成本高。（这本身是一个设备与工艺难点。）
- **单晶金刚石**：尺寸越大，位错、孪晶概率越高，可用面积比例迅速下降。

## 四、怎么把金刚石用到芯片上：三条技术路线

**这三条是竞争关系，不是等级关系。**

| 路线 | 做法 | 公开可见的代表 |
| --- | --- | --- |
| **键合** | 把金刚石片与晶圆在低温/室温下贴成一体 | 苏州晶和半导体；Element Six |
| **直接生长** | 在 GaN 上直接长一层 CVD 金刚石 | AFRL / TriQuint（现 Qorvo）。公开工艺：MOCVD 长 AlGaN/GaN 于高阻 Si(111)，去掉 Si 与过渡层，镀 50 nm 介质，再长 100 μm CVD 金刚石 |
| **嵌入** | 用飞秒激光把 GaN 芯粒切下，嵌进预加工的单晶金刚石基底微腔，靠 20 μm 厚导热膜传热 | MIT，2026 IEEE IMS |

关心键合这条路的，看下一节。

## 五、键合这条路：SAB 是什么

**SAB（Surface Activated Bonding，表面活化键合）**：把两块材料表面在超高真空里用原子束"擦干净"，让它们在**室温**下直接粘成一体。不用胶、不用焊料、不加热。中文也叫"表面活化键合""常温直接键合"。

**为什么"不加热"是全部意义所在**：

| 传统做法 | 温度 | 问题 |
| --- | --- | --- |
| 亲水键合 / 熔融键合 | 400–1100 ℃ 退火 | 两种材料热胀冷缩不一样，一冷就翘、就裂 |
| 阳极键合 | 300–500 ℃ + 高压 | 只适用硅-玻璃这类特定组合 |
| 共晶键合 / 焊料键合 | 200–400 ℃ | 中间夹一层金属，导热差一截 |
| 热压键合 | 300–500 ℃ + 加压 | 同上，界面有合金层 |
| **SAB** | **室温** | 没有热应力问题，但要求表面极干净、真空极高 |

金刚石和 GaN 的热膨胀系数差了好几倍。一加热再冷却，界面必然积累应力——这是"金刚石贴 GaN"几十年做不好的核心原因。**SAB 的价值就是绕开加热这一步。** 代价是表面必须在原子尺度上干净，所以需要**超高真空（≤10⁻⁷ Pa）**和**原子束活化**。

**工艺要点**（据公开描述与相关课题组论文）：表面研磨清洗 → 进腔抽到 ≤10⁻⁷ Pa → 用氩（或氦）快原子束照射表面、造出悬空键 → 超高真空下对准贴合 → 可选低温退火 → 后处理（例如把原支撑衬底磨掉）。

**界面发生了什么**（这是这项技术最值钱的部分）。据公开报道的 GaN/金刚石键合面分析：

| 阶段 | 界面中间层厚度 | 成分 |
| --- | --- | --- |
| 键合后（未退火） | 约 5.3 nm | 无定形碳 + 金刚石的混合层 |
| 700 ℃ 退火后 | 变薄 | 无定形碳开始转化 |
| 1000 ℃ 退火后 | 约 1.5 nm | 出现晶格条纹，即无定形碳转成了金刚石 |

**要留意的两个数**：

- **3C-SiC–金刚石界面热边界电导（TBC）≈ 55 MW·m⁻²·K⁻¹**，且 1100 ℃ 退火后界面不分层（Small, 2023，见 [原始来源](原始来源.md)）。这是这个方向上少见的、有同行评审论文支撑的界面数字。
- 中间层常要夹一层 **3C-SiC**（立方碳化硅），形成 GaN/3C-SiC/金刚石三明治。3C-SiC 与 GaN 晶格匹配好、与金刚石也挂得住，且自身导热不低——相当于一层"导热的双面胶"。

**注意"常温"与"高温"不矛盾**：工艺是"先常温贴住、再高温强化"。常温解决的是贴合时不产生热应力；退火解决的是把界面从物理吸附变成化学键。退火发生在已经贴牢之后。

## 八、术语速查

| 词 | 大白话 |
| --- | --- |
| **第三代半导体** | GaN（氮化镓）、SiC（碳化硅）。"宽禁带"，做射频功放和功率器件 |
| **第四代 / 超宽禁带** | Ga₂O₃（氧化镓）、AlN（氮化铝）、金刚石。更极端、更不成熟 |
| **衬底** | 芯片底下那层"地基" |
| **外延** | 在衬底上再长出一层单晶薄膜，器件做在外延层里 |
| **MOCVD** | 金属有机化学气相沉积，长 GaN 外延的主流设备 |
| **CVD 金刚石** | 化学气相沉积"长"出来的金刚石（不是天然、也不是高温高压合成） |
| **MPCVD** | 微波等离子体 CVD，长金刚石最常用的方法 |
| **多晶 / 单晶** | 多晶＝很多小晶粒拼起来，有晶界；单晶＝一整块。单晶导热更好但做不大 |
| **SAB** | 表面活化键合，常温直接键合，见第五节 |
| **FAB** | 快原子束，用氩（或氦）原子束轰击表面做活化 |
| **异质集成** | 把不同材料、不同工艺做出来的东西拼成一个整体 |
| **混合键合** | 金属（铜）和介质同时键合，先进封装（3D 堆叠）的核心工艺 |
| **W2W / C2C / C2W** | 晶圆对晶圆 / 芯片对芯片 / 芯片对晶圆，三种键合模式 |
| **退火** | 键合后加热，让界面从物理吸附变成化学键 |
| **热失配** | 两种材料热胀冷缩不一样，一加热冷却就翘曲开裂 |
| **TBR / TBC** | 热边界电阻 / 热边界电导，界面导热能力的度量 |
| **声子** | 晶格振动的量子化。半导体里热主要靠声子搬运，界面处声子会散射 → 产生热阻 |
| **晶界** | 多晶材料里晶粒之间的界面，会散射声子、降低导热 |
| **HEMT** | 高电子迁移率晶体管，GaN 射频/功率器件的主流结构 |
| **GaN-on-SiC / on-Si / on-Diamond** | GaN 长在什么衬底上。SiC 是当前主流，金刚石散热最优但最不成熟 |
| **TFLN** | 薄膜铌酸锂，做高速光调制器的材料，硅光/AI 光互连的关键 |
| **CPO** | 光电共封装，把光模块和芯片封在一起 |
| **首台套** | 国内首台（套）重大装备认定。苏州的奖励标准：省级 80 万元、苏锡常 50 万元 |
